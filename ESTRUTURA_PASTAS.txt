PASSOS PARA INSTALAÇÃO NO XAMPP:
=============================================================================

1. Crie a pasta base:
   C:\xampp\htdocs\IA\

2. Copie TODAS as pastas listadas acima para dentro de IA\

3. CRIE MANUALMENTE as pastas:
   C:\xampp\htdocs\IA\storage\
   C:\xampp\htdocs\IA\storage\logs\

4. Configure o banco em config/config.php:
   - DB_HOST = localhost
   - DB_NAME = gestao_ti
   - DB_USER = root
   - DB_PASS = (vazio no XAMPP)

5. No navegador, acesse:
   http://localhost/IA/public/

6. Login padrão:
   Usuário: admin
   Senha: gestaoti2024
